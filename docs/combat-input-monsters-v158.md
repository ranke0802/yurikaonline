# v0.02.158 입력 및 몬스터 전투 수정

위치·전사·궁수의 H/K 조준은 버튼을 놓을 때 한 번 실행됩니다. 키 반복, 마우스/터치 드래그, 취소와 포커스 이탈에서도 누르는 동안 피해·비용이 발생하지 않습니다. 기존 마법사의 반복 시전은 유지합니다.

소환 지면 스킬은 원본 몬스터와 같은 범위 도형과 세로 방향 이펙트를 사용하며 몸체 뒤에 그립니다. 경고→충격→잔류 프레임을 구분하고 돌진 중에도 이펙트를 유지합니다. 소환 미사일은 기존 미사일 그림과 진행 방향을 사용합니다. 시각 스냅샷은 피해를 실행하지 않습니다.

에몽가 착지 장판은 명시된 0초 경고를 보존하고 5초 피해 수명 동안 표시됩니다. 500ms 간격 10회 피해가 낮은 프레임 속도에서도 유지되며 종료 시 추가 타격하지 않습니다. 원본 에몽가 미사일은 발사자 및 다른 몬스터와 충돌하지 않습니다. 플레이어 미사일의 몬스터 타격은 유지됩니다. 현재 원본 정의에서 missile 스킬을 사용하는 종은 에몽가입니다.

로컬 모드의 몬스터 피해는 참여 중인 본인 캐릭터에게만 전달합니다. 기존 로컬 PvP 차단과 마을·보호막 등의 피해 방어 처리는 유지됩니다.

## 검증

- 전체 CI 단위·자산 검증 명령 통과. 미사일 수정 후 관련 86개 테스트 재검증.
- 브라우저 회귀 25개와 신규 미사일 브라우저 검사 통과.
- 실제 에몽가 두 발 비행, 플레이어 HP 10000→9982, 발사자 HP 620 유지 확인.
- 파이어볼 24,600사례 및 온라인 스냅샷·권한 40사례 통과.
- 원본 12종·소환 8종의 46개 시퀀스, 598프레임 촬영. 소환 지면 렌더러를 별도 브라우저 컨텍스트의 원격 렌더링 경로와 260시점 비교해 픽셀 일치.
- 로컬 Node Firebase SDK 캐시/직업 귀환 검사는 시간 초과. 브라우저 SDK 귀환 검사는 통과. 배포 CI에서 Node SDK 검사도 재실행하며, 성공하지 않으면 배포 단계에 도달하지 않습니다.

실제 운영 다중 사용자 및 실물 Android 검증을 의미하지 않습니다. 기존 마법사 원화, 로딩 화면, PWA 아이콘, 야영지 원화는 변경하지 않습니다. 거절된 신규 마법사 atlas는 적용하지 않았으며 마법사 방향별 공격 모션은 별도 미완료 작업입니다.

# v0.02.179 첫 모험과 메뉴 입력

새 로컬 프로필로 PC 키보드와 모바일 세로·가로 터치를 직접 사용해 다음 문제를 재현했습니다.

| 우선순위 | 재현 | 변경 |
| --- | --- | --- |
| 1 | 이동 패드를 0.2초씩 8번 조작해 약 239픽셀을 이동해도 첫 훈련 진행도가 0/36. 달리기 상태만 집계했습니다. | 짧은 걷기도 기존 이동 프레임 집계에 포함합니다. 이동 속도와 36회 완료 조건은 유지합니다. |
| 2 | 길게 이동하면 내부 집계는 28인데 HUD는 0/36으로 남았습니다. | 튜토리얼 이벤트가 집계되면 진행 문구만 갱신합니다. 퀘스트 패널 전체나 안내창을 매 프레임 재생성하지 않습니다. |
| 3 | 안내대로 B를 눌러도 가방이 닫히지 않습니다. I와 Shift+S도 같은 문제입니다. | 해당 메뉴가 열린 동안 같은 키로 정상 닫기 경로를 실행합니다. 스탯 저장 확인, 취소, 튜토리얼 닫기 제한을 그대로 적용합니다. |

문자 입력 중이거나 중첩 확인창이 열려 있을 때, Ctrl/Alt/Meta 조합과 반복 키다운에는 메뉴를 닫지 않습니다. 단축키 힌트를 숨겨도 메뉴 토글은 사용할 수 있습니다. 메뉴 안의 이동·공격 차단은 기존 키보드 처리기에 남아 있습니다.

## 재현과 검증

로컬 HTTP 서버 8100을 실행한 뒤:

```sh
CHROMIUM_PATH=/usr/bin/chromium node scripts/validate-gameplay-entry-browser.cjs
```

`QA_BASE_URL`과 `QA_OUTPUT`으로 테스트 대상과 결과 경로를 바꿀 수 있습니다. 모든 브라우저는 신규 `?local=1` 프로필, 동일 출처 요청만 허용하고 서비스 워커를 차단합니다. 운영 로그인이나 운영 저장 데이터를 사용하지 않습니다.

신규 검증은 1280×800, 393×852, 852×393에서 실제 짧은 입력, 멈춘 동안 집계 불변, 표시 집계 일치, 기본 공격, 12단계 훈련 완료, 스탯 저장 취소·확정, 메뉴 단축키·문자 입력·반복 입력, 회전, 브라우저 뒤로가기와 저장 후 야영지 재입장을 확인합니다. 튜토리얼 단계나 진행도를 강제로 넘기지 않습니다. GitHub Actions에서 배포 전과 배포 후 모두 실행합니다.

기존 정적 검증 전체와 튜토리얼 안내·스탯 취소·직업별 훈련, 설정 종료, 사망·재시도, HUD 입력, 직업 교차 입력 회귀를 함께 확인합니다. 실제 스마트폰 성능·온라인 다중 사용자 동기화는 이번 로컬 플레이 검증의 범위에 포함되지 않습니다.

원화, 승인된 WebP, 생명의 구슬 효과, 공격·회복 수치, 성장·경제·소환수·강화 규칙은 변경하지 않았습니다.

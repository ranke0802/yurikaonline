# 소환수 버서크 표시와 생명의 구슬 귀환 타격

버서크의 실제 효과가 적용된 소환수 하단에 기존 상태 이미지의 버서크 아이콘을
표시한다. 생명의 구슬은 돌아오는 경로에서도 적마다 한 번 추가 타격한다.

## 소환수 상태

- 기존 대상은 시전자를 제외한 현재 파티원과 시전자 자신의 생존 소환수다.
  다른 플레이어 소유의 소환수나 시전 이후 새로 소환한 개체로 대상을 늘리지 않는다.
- 기존 10초 지속, 이동 ×1.25, 공격 속도 ×1.7, 기본 공격력 ×1.2 및 장비 보정은
  그대로다. 표시 여부는 실제 배율 계산이 읽는 컨트롤러의 `berserkUntil`에서 가져온다.
  남아 있는 `classStatuses` 값만으로 아이콘을 표시하지 않는다.
- `status.webp`의 기존 버서크 칸을 22 월드 px로 몸체 하단에 그린다. 상단의 소유
  이름표·HP 바와 분리하며 새 이미지나 벡터 효과를 만들지 않는다.
- 기존 소환수 프로필 동기화에 서버 시각 기준 만료 시각을 추가한다. 관찰자는
  기존 서버 시간 보정값으로 읽고, 패킷 없이도 만료된다. 수신 값은 유효한 숫자와
  최대 10초 잔여 시간으로 제한한다. 이전 클라이언트의 필드 없는 패킷은 표시하지 않는다.
- 만료·죽음·최대 수 초과 교체·소환 해제·컨트롤러 폐기·재입장 시 상태 표시가 사라진다.
  네트워크로 새 버프 효과를 발동하지 않으며, 표시 상태만 기존 소환수 동기화에 담는다.

## 귀환 타격 규칙

- 출발은 기존 최대 3대상, 대상당 3회, 0.25초 간격을 유지한다.
- 귀환은 별도의 적별 기록으로 각 구슬이 각 적을 한 번 타격한다. 출발의 3대상
  제한을 귀환에 공유하지 않으므로, 출발 때 맞지 않은 적도 귀환 경로에서 맞을 수 있다.
  사거리 판정은 기존 발사 중심에서 560px 이내를 유지한다.
- 귀환 피해는 발사 때 저장한 기존 한 타의 피해와 같다. Lv.1 ATK 70%에서 레벨당
  5%p씩 늘어 Lv.8 105%이며, 기존 장비·방어력·네트워크 수락 판정을 거친다.
- 빠른 귀환 이동의 시작~끝 선분을 검사하며 마지막 도착 이동도 포함한다.
  1/120초 내부 진행과 구슬별 귀환 명중 집합으로 저프레임 누락과 중복을 막는다.
  귀환 이동은 기존처럼 벽을 통과하지만 대상 접촉의 벽 검사는 유지한다.
- 출발과 귀환에서 **실제로 수락된 피해**를 같은 구슬 회복 누적에 더한다.
  귀환에서 처음 만난 적도 회복에 기여한다. 도착 시 한 번만 회복하고, 기존
  `min(발사 시 ATK 회복 상한, floor(누적 실제 피해 ×20% + 기존 무기 회복))`를 유지한다.
  현재 최대 HP를 초과하지 않으며 아군에게 남는 회복을 나눠 주지 않는다.
- Lv.1 ATK 100 구슬이 귀환에서 처음 70 피해를 주면 회복은 상한 12다.
  피해가 1뿐이면 정수 계산상 회복은 0이다. 다수 대상이나 4구슬도 각 구슬 상한을
  넘지 않는다. 슬롯 수·귀환 속도 540px/s·조준·취소·사망/필드 변경 정리는 유지한다.

## 검증

```sh
npm run validate:return-berserk
QA_BASE_URL=http://127.0.0.1:8101 npm run validate:return-berserk-browser
QA_BASE_URL=http://127.0.0.1:8101 node scripts/validate-witch-ranged-browser.cjs
QA_BASE_URL=http://127.0.0.1:8101 node scripts/validate-life-orb-impact-browser.cjs
QA_BASE_URL=http://127.0.0.1:8101 node scripts/validate-render-frame-completeness-browser.cjs --mode=matrix
```

브라우저 검증은 실제 클릭/탭으로 소환·포션 사용·야영지 복귀·재진입·구슬 발사를
수행한다. 시간·표적·원격 패킷은 독립 로컬 프로필 안에서 구성한다. PC 1280×800,
세로 393×852, 가로 852×393에서 소환수 3마리 표시, 만료, 재사용, 사망, 교체,
재입장, 출발+귀환 동일 적, 귀환 첫 대상, 미명중, 4구슬, 4Hz, 실제 touchCancel을 검사한다.

단위 검증은 4·20·60·144Hz의 동일 피해/회복, 최종 도착 선분, 재진입 호출,
거부·벽·사거리·죽음·폐기, 서버 시각 보정과 오래된 패킷 만료를 포함한다.
기존 공격력/무기/구슬 테스트는 출발과 귀환을 구분한 기대값으로 갱신했다.
렌더 완전성 검사와 고의 누락 대조 검사는 유지한다.

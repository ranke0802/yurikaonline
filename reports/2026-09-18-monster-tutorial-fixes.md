# 몬스터 방향·튜토리얼 표시 개선

## 수정

- 돌진 예고선의 시작점에만 적용되던 높이 오프셋을 제거해 예고선, 조준점, 이동 벡터를 일치시켰다. 시전 중 넉백·게스트 보간으로 시작점이 움직이지 않으며, 이동은 예고한 목적지에서 멈춘다.
- 돌진 충돌을 플레이어 중심과 이동 구간으로 검사해 빠른 돌진의 판정 누락을 막았다. 팝업 일시정지 후 속도 복원과 원격 `charging` 상태 수신 시 이동 타이머 시작도 보완했다.
- 세로로 솟는 이펙트 그림을 통째로 회전·반전하던 처리를 제거했다. 지면 화살표와 진행 방향 뒤쪽 잔상이 방향을 표현하고, 직선 공격의 충격 이펙트는 경로를 따라 바로 세워 배치한다.
- 실제 WebP 시트는 균등한 5×4 간격이 아니었다. 그림 사이의 빈 구간을 측정해 셀 경계를 지정하고, 이전 프레임 바닥이 다음 프레임 위쪽에 잘려 보이는 문제를 수정했다. 별도 균열 이펙트 시트는 기존 전체 프레임을 사용한다.
- 튜토리얼의 같은 영역·포함된 영역 강조를 합치고, 저장 단계는 안내 문구에 맞는 닫기 버튼 하나를 강조한다. 확인창에서는 확인 버튼과 저장 안내로 전환한다.
- 팝업 이동·애니메이션·스크롤을 강조 박스가 따라가며, 가려지거나 화면 밖으로 벗어난 대상은 표시하지 않는다. 화면 회전 시 해당 배치의 튜토리얼 설정을 다시 적용한다.
- 강조 박스 확대 애니메이션을 제거하고 투명도 변화만 유지한다. 위치가 그대로면 기존 DOM을 재사용하고, 강조 해제 시 추적도 중단한다.

## 검증

- `npm run validate`: 퀘스트, 월드, 자산, UI, 런타임, 투사체 및 기존 개선 검증 통과.
- `npm run validate:combat`: 14개 통과. 8방향, 목표 초과, 넉백, 일시정지 재개, 게스트 보간/상태 전환, 플레이어 중심 충돌, 좌표 0, 중복 시전 효과, 시트 프레임 경계를 검사한다.
- 새 Playwright 검사 8개 통과. 실제 HTML/CSS로 1280×720, 390×844, 844×390에서 튜토리얼 12단계 전환, 저장 확인창, 중복 제거, 스크롤·가림·위치 변경·정리와 이펙트 렌더링을 확인했다.
- 기존 브라우저 레이아웃 검사 통과. 로그인 검사는 최초 실행에서 폰트 대기 시간 초과와 서비스 워커 재로딩 경합을 만났다. 서비스 워커 차단 및 캡처의 폰트 대기 생략 환경에서 재실행하여 로그인 진입, 카메라 설정 저장, 런타임 오류 검사 모두 통과했다. 앱의 서비스 워커 코드는 변경하지 않았다.
- 로컬 macOS의 Chrome과 `python3`를 사용했다. 튜토리얼 검사는 외부 요청을 차단하고, 로그인 검사는 운영 데이터베이스 요청을 차단했다. 실사용 계정의 다중 접속 플레이나 운영 배포는 수행하지 않았다.

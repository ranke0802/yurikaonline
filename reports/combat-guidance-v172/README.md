# v0.02.172–173 — CBT03 전투 안내

반복되는 같은 전투 거절이 채팅 이력을 밀어내던 문제를 줄이고, 실제 거절·권한 대기 분기에 이유를 표시한다. 전투 실행 조건, 자원 비용, 피해/상태 판정과 네트워크 권한 처리는 그대로다.

- 같은 전투 실패는 기존 안내가 남아 있는 동안 중복 추가하지 않는다. 일반 채팅이 중간에 와도 순서·스크롤을 바꾸지 않는다. 다른 이유는 즉시 새로 표시하고, 성공·명시적 취소·컨트롤러 재진입은 다음 실패를 다시 안내할 수 있게 한다. 일반 시스템 로그와 채팅에는 이 억제를 적용하지 않는다.
- HP 부족의 완전한 문구를 `HP 80%` / `초과 필요` 두 줄로 유지하며 버튼 내부의 이유 영역만 위로 옮긴다. 전투 대기도 `전투 반영` / `대기`로 고정해 대체 글꼴에서 세 줄이 되는 것을 막는다. 390×844 / 844×390 로컬 측정에서 스킬명과 겹침0, 이름과 이유 간격은 각각 약4.91 / 5.66 CSS px다. 기존 v171 기록과 비교한 네 버튼의 위치·크기는 동일하다.
- 소환 정보 미준비/생성 위치 없음, 돌진 전방 막힘, 다른 짧은 스킬 시전 중 파이어볼 조준 거절을 해당 실제 반환 지점에서 설명한다. 지속 번개를 끊고 파이어볼로 전환하는 허용 동작은 유지한다.
- 기존 호스트 복원·인계 차단 상태를 읽어 관련 몬스터 전투 버튼에 `전투 반영 대기` 힌트를 표시한다. v173에서는 기존 쿨다운 숫자가 보일 때만 버튼 위쪽에 `동기화 중` 한 줄로 표시해 숫자와 이름을 함께 읽을 수 있게 한다. 새로 추가한 마법사 `시전 중` 안내도 숫자가 있으면 같은 한 줄 배치를 쓴다. 전체 설명은 접근성 라벨에 유지한다. 자기 배리어/아군 강화는 기다림 때문에 사용 불가로 표시하지 않는다. 힌트는 입력을 차단하지 않고 실제 차단 상태가 끝나면 해제된다. 일반 연결 끊김을 임의로 호스트 대기라고 부르지 않는다.

첫 지역 개선 제안: 오두막 위험 신호 → 슬라임 3마리 조작 학습 → 방호석 선택·점화 → 원거리 견제와 근접 회피 → 두 플레이어가 다른 방호석 유지 → 보호 대상에게 돌아가 결과 대화 → 보스 패턴 학습. 수치·서사는 운영 데이터에 반영하지 않았다.

```json
{
  "id": "proposal_cabin_ward",
  "objectives": [
    {"type": "interact", "target": "ward_stone", "count": 1},
    {"type": "defend", "target": "cabin", "durationSeconds": 45}
  ],
  "authority": "server"
}
```

interact/defend는 현재 없는 목적 타입이므로 스키마·서버 진행 검증을 먼저 추가해야 한다. 우선순위는 서버 권한 → 첫 지역 경험·계측 → 적 역할·협동 기믹 → 독자 에셋 검토 → 신규 지역이다. 대규모 밸런스·콘텐츠·IP 교체는 수행하지 않았다.

# Yurika 오프라인 테스트

정식 서비스와 별개인 v0.02.183 로컬 테스트판입니다.
계정 로그인 없이 혼자 플레이하며 진행 기록은 현재 브라우저에만 저장됩니다.

## 시작하기

1. ZIP을 폴더에 풀어 주세요.
2. Python 3.10 이상이 있는 컴퓨터에서 해당 폴더를 열고 `python3 serve.py`를 실행하세요.
   Windows에서는 `py -3 serve.py`로 실행할 수 있습니다.
3. 같은 컴퓨터의 브라우저에서 `http://127.0.0.1:8183/`을 여세요.
4. 이름을 입력해 로컬 캐릭터를 만들고, 원정 출발 → 이 지역에서 이어하기를 누르세요.

처음에는 게임 안의 이동·공격·메뉴 안내를 따라 진행하면 됩니다.
야영지의 캐릭터 메뉴에서 마법사·마녀·전사·궁수를 선택할 수 있습니다.

## 조작

- 이동: WASD / 방향키. 터치 화면은 왼쪽 조이스틱.
- 기본 공격: J 또는 화면 오른쪽 공격 버튼. 마녀·전사·궁수는 짧게 눌렀다 놓으세요.
- 스킬: H / U / K 또는 해당 화면 버튼.
- 가방: B, 능력치: I, 스킬 메뉴: Shift+S.
- 종료·저장: 야영지 복귀 버튼 또는 설정의 게임 나가기.

## 제한

온라인 계정, 멀티플레이, 친구·파티 기능, 계정 복구 및 다른 기기 동기화는 지원하지 않습니다.
브라우저 저장소 삭제·시크릿 모드 종료·주소 또는 포트 변경 시 기존 기록이 보이지 않거나
사라질 수 있습니다. 운영 계정 진행 내용과 합쳐지지 않습니다.

인터넷이 없어도 서버 실행 중에는 플레이할 수 있습니다. 서버 종료 후 재접속은 지원하지
않으며 index.html을 더블클릭하는 file:// 실행도 지원하지 않습니다.
이 주소는 해당 컴퓨터 내부 주소이며 휴대폰이나 다른 컴퓨터에서 접속하는 공유 URL이 아닙니다.

기존 화면 구성·전투 코드·WebP 이미지 바이트를 유지했습니다. 외부 웹폰트 대신 묶음에
포함한 Noto Sans CJK KR의 로컬 글꼴을 사용하므로 글자 모양은 온라인판과 다를 수 있습니다.
효과음과 음악은 원래 게임의 브라우저 오디오 합성 방식을 사용합니다.

원본 기준: mmorpg_online / e34456219cbeaa2679625f7e109b10d1377b2706.
무결성 확인: `python3 serve.py --verify-only`. 파일 목록과 SHA-256은 contents-manifest.json에 있습니다.

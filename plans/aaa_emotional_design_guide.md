# AAA급 감정 설계: "플레이어를 울리는" 프롤로그 완성 가이드

**목표**: 산나비, The Last of Us, To the Moon 수준의 감정적 임팩트
**평가 기준**: "펑펑 울었다" 플레이어 피드백 30%+

---

## 🎯 "우는 게임"의 비밀: 3대 핵심 법칙

### 법칙 1: Attachment Through Agency (능동적 애착)
> "플레이어가 사랑한 것이 아니라, 플레이어가 지킨 것을 잃어야 운다."

**나쁜 예**:
- 시네마틱으로 아내의 죽음을 보여줌
- 플레이어: "슬프네... 다음"

**좋은 예 (The Last of Us)**:
- 플레이어가 Sarah를 직접 안고 도망침
- Sarah를 지키려 버튼을 연타함
- 그럼에도 불구하고 총에 맞음
- 플레이어: "내가 지키지 못했다" → **죄책감 = 강력한 감정**

### 법칙 2: The Inversion Trick (전복의 기술)
> "행복했던 기억이 고통으로 변할 때, 플레이어는 운다."

**산나비의 교훈**:
- 초반: 밝고 유쾌한 동료와의 대화
- 후반: 그 동료가 사실은...
- 플레이어: 초반 장면을 다시 떠올리며 울음

**적용**:
- 아내와의 행복한 순간을 먼저 플레이
- 출산 장면에서 그 행복이 무너짐
- → 대비가 클수록 감정 폭발

### 법칙 3: Silence is Louder (침묵의 힘)
> "가장 슬픈 순간에는 음악도, 대사도 없어야 한다."

**To the Moon의 마스터클래스**:
- 클라이맥스: 모든 BGM 정지
- 캐릭터들의 대사 없음
- 오직 바람 소리와 발걸음 소리
- 플레이어: "......" (눈물)

## 🎬 AAA급 프롤로그: 완전 재설계

### Phase 0: Cold Open (0:00 - 3:00)
**"행복했던 과거"를 플레이하게 하라**

#### Scene 0A: 아내와의 마지막 평범한 날 (Interactive)
```
시간: 출산 1주일 전
장소: 오두막 거실, 따뜻한 오후

플레이어 제어:
1. 아내가 앉아 있는 의자에 다가가기 (WASD)
2. 아내의 배에 손 얹기 (클릭)
   → 아기의 발차기 느낌 (진동 피드백)
   → 아내: "느껴져? 활발한 아이야."
   
3. 창가에서 꽃 꺾어오기
   → 아내에게 건네기
   → 아내: (미소) "고마워. 당신은 좋은 아빠가 될 거야."
   
4. 마법서 읽기 (선택지)
   - "치유 마법" 선택 시: 아내가 좋아함
   - "공격 마법" 선택 시: 아내가 걱정함
   
5. 해질녘, 함께 창밖 보기
   → 아내: "우리 셋이서 여기 오래오래 살자."
   → 주인공: "물론이지."
```

**감정적 효과**:
- 플레이어는 이 일상이 **자신의 손으로 만든 기억**이 됨
- 나중에 이 장면들이 "잃어버린 행복"으로 변함
- 아내의 대사가 복선이자 비극적 아이러니가 됨

**시간 투자**: 3분 (길어 보이지만 필수)
- The Last of Us 프롤로그: 20분
- 당신의 게임: 3분도 충분히 짧음

### Phase 1: The Storm (3:00 - 7:00)
**"출산의 밤" - Interactive QTE Hell**

#### Scene 1A: 급작스러운 진통 (QTE 시작)
```
밤, 심한 폭풍우
아내: "여보... 아파..."

Interactive QTE:
1. 아내를 침대로 옮기기 (마우스 드래그, 부드럽게)
   → 실패 시: 아내가 신음 (죄책감 유발)
   → 성공 시: "고마워... 당신이 있어서..."

2. 뜨거운 물 준비 (스페이스바 연타)
   → 진행률 바 (긴박감)
   → 아내의 비명 소리가 배경에 계속

3. 산파 부르러 가기
   → 폭풍우 속 달리기 (WASD)
   → 번개가 치며 화면 깜빡임
   → 플레이어는 절박함을 느낌

4. 산파와 함께 돌아오기
   → 산파: "서둘러야 해요!"
```

**핵심**: 
- 플레이어가 "최선을 다하게" 만들어야 함
- QTE가 쉬우면 안 됨 (약간의 긴장감)
- 하지만 실패해도 스토리는 진행

#### Scene 1B: 출산 - The Point of No Return
```
Interactive 요소:
1. 산파의 지시 듣기
   → "손 잡아주세요!" → E키 홀드
   → "수건 가져오세요!" → 마우스 클릭
   
2. 아내와 눈 맞추기 (시선 제어)
   → 카메라를 아내 얼굴로 유지
   → 아내: "당신... 사랑해..."
   → 주인공: "나도... 나도 사랑해!"

3. 아기 울음소리
   → 모든 소음이 사라짐
   → 오직 아기 울음만 들림 (감각 집중)
   
4. 주인공: "여보! 우리... 우리 해냈어!"
   → 아내를 보려고 카메라 돌림
   
5. [The Twist]
   → 산파의 표정 (클로즈업)
   → 산파의 손이 천천히 아내의 목에서 떨어짐
   → 심장박동 소리 멈춤
   → **완전한 침묵** (5초)
```

**감정 폭발 포인트**:
```
침묵이 깨짐:

아기 울음소리 (다시 시작)
주인공의 떨리는 호흡
산파: "...죄송합니다."

[음악 없음, 대사 없음]
[플레이어 제어권 박탈]

자동 컷신:
- 주인공이 천천히 아내의 손을 잡음
- 손이 차가움 (진동 피드백 정지)
- 주인공의 어깨가 떨림
- 눈물이 아내의 손에 떨어짐

[여전히 음악 없음]
[여전히 대사 없음]

화면 천천히 페이드 투 블랙
```

**왜 이게 AAA인가?**
- 플레이어는 "내가 최선을 다했는데도" 실패함
- 침묵이 감정을 극대화
- 산파의 "죄송합니다" 한 마디가 모든 것을 전달
- 긴 설명 대사 없음 = Show Don't Tell의 극치

### 1. 음향 설계의 극치

#### 레이어드 사운드 시스템
```javascript
// 감정 상태에 따른 동적 음악
const EmotionalSoundSystem = {
    layers: {
        base: 'piano_soft.mp3',      // 기본 멜로디
        tension: 'strings_low.mp3',   // 긴장감
        hope: 'violin_high.mp3',      // 희망
        tragedy: 'cello_deep.mp3'     // 비극
    },
    
    mixForScene: (emotionLevel) => {
        // 출산 직전: base + tension
        // 아기 울음: base + hope
        // 아내 죽음: base + tragedy (then fade all to silence)
```

## 결론: "펑펑 울리는" 프롤로그의 공식

```
1. 행복을 직접 플레이하게 하라 (3분)
2. 그 행복을 플레이어의 손으로 잃게 하라 (4분)
3. 침묵으로 감정을 극대화하라 (30초)
4. 새로운 목표를 플레이어 스스로 느끼게 하라 (2분)
5. 일상을 통해 유대를 강화하라 (5분)
6. 위기를 통해 각오를 다지게 하라 (3분)

총 플레이 타임: 18분
목표 감정: "슬픔 → 희망 → 결의 → 애착 → 공포 → 안도 → 결연"
```

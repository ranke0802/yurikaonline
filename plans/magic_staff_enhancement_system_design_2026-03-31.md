# 장비 강화 및 마력의 지팡이 설계서

작성일: 2026-03-31

## 목표

- 대왕 슬라임을 첫 장비 파밍 보스로 만든다.
- 장비 파밍, 접두사 랜덤 옵션, 강화 재료 파밍을 한 루프로 묶는다.
- 무기 외형과 스킬 이펙트가 함께 바뀌는 "보이는 성장"을 만든다.
- 추후 코드 구현 시 데이터 주도 방식으로 확장 가능하게 설계한다.

## 이번 설계 범위

- 무기 1종: `마력의 지팡이`
- 강화 재료 1종: `무기 강화석`
- 접두사 3종
- 강화 수치: `+1 ~ +10`
- 접두사별 오오라 및 강화 단계별 강화 오오라 규칙

## 핵심 규칙

1. 현재 시점에서 장비 드랍은 `대왕 슬라임`만 담당한다.
2. 모든 몬스터는 `0.1%` 확률로 `무기 강화석`을 드랍한다.
3. 대왕 슬라임은 `마력의 지팡이`를 드랍한다.
4. 마력의 지팡이는 드랍 시 3개 접두사 중 하나가 랜덤하게 붙는다.
5. 접두사 효과 수치는 드랍 시 1회 랜덤 롤되고, 이후 강화와 별개로 고정된다.
6. 강화는 무기에만 적용되며 `+1 ~ +6`은 안전 강화다.
7. `+7 ~ +10` 실패 시 `50%` 확률로 장비가 파괴된다.
8. 파괴되지 않은 실패는 강화 수치 유지로 가정한다.

## 기본 아이템 사양

- 이름: 마력의 지팡이
- 슬롯: 무기
- 기본 공격력: `+5`
- 치명타 확률: `+5%`
- 마나 회복력: `+3`
- 강화 1단계당:
  - 기본 공격력 `+1`
  - 치명타 확률 `+1%`

## 접두사 설계

### 1. 별빛의

- 이름 예시: `별빛의 마력의 지팡이`
- 스킬 변경: 매직 미사일 -> 금빛 매직 미사일
- 추가 효과:
  - 매직 미사일 피해 `20% ~ 50%` 증가
- 시각 테마:
  - 연한 금빛 오오라
  - 은은한 별가루
  - 미사일 발사 시 짧은 황금 잔광

### 2. 푸른 불꽃의

- 이름 예시: `푸른 불꽃의 마력의 지팡이`
- 스킬 변경: 파이어볼 -> 푸른 파이어볼
- 추가 효과:
  - 파이어볼 또는 화상 피해로 몬스터 사망 시 폭발
  - 폭발 피해는 파이어볼 피해의 `20% ~ 50%`
  - 폭발 피해를 받은 주변 적에게 화상 부여
- 시각 테마:
  - 청람색 오오라
  - 푸른 불꽃 잔상
  - 폭발 시 파란 불꽃 링

### 3. 붉은 섬광의

- 이름 예시: `붉은 섬광의 마력의 지팡이`
- 스킬 변경: 일반 공격 체인 라이트닝 -> 붉은 전격
- 추가 효과:
  - 일반 공격 피해 `20% ~ 50%` 증가
  - 기존 MP 흡수에 더해 HP도 흡수
  - 전격 이펙트가 더 굵고 강하게 표현됨
- 시각 테마:
  - 붉은 오오라
  - 미세한 전기 스파크
  - 체인 라이트닝에 붉은 후광 추가

## 강화 규칙

| 목표 강화 | 성공 확률 | 실패 시 파괴 확률 | 비고 |
| --- | --- | --- | --- |
| +1 | 100% | 0% | 안전 |
| +2 | 100% | 0% | 안전 |
| +3 | 100% | 0% | 안전 |
| +4 | 100% | 0% | 안전 |
| +5 | 100% | 0% | 안전 |
| +6 | 100% | 0% | 안전 |
| +7 | 50% | 50% | 위험 강화 시작 |
| +8 | 25% | 50% | 위험 |
| +9 | 15% | 50% | 고위험 |
| +10 | 5% | 50% | 최고 단계 |

### 강화 실패 가정

- 이번 설계에서는 유저가 따로 언급하지 않은 `강화 수치 하락`은 넣지 않는다.
- 즉 실패 결과는 둘 중 하나다.
  - 장비 유지, 강화 수치 유지
  - 장비 파괴, 복구 불가

## 드랍 설계

### 글로벌 드랍

- 모든 몬스터
  - `무기 강화석` 0.1%

### 보스 전용 드랍

- 대왕 슬라임
  - `마력의 지팡이` 100%
  - 드랍 시 접두사 1종 랜덤 부여
  - 접두사 옵션 수치 랜덤 롤 저장

## 아이템 인스턴스 구조 제안

장비는 단순 수량형 아이템과 다르게 인스턴스 데이터가 필요하다.

```json

    "missileDamageBonus": 0.37
  },
  "baseStats": {
    "attackPower": 5,
    "critRate": 0.05,
    "mpRegen": 3
  }
}
```

## 장착 및 전투 반영 규칙

### 공통

- 장착 시:
  - 공격력
  - 치명타 확률
  - 마나 회복력
  - 강화 보너스
  - 접두사 전용 전투 효과
  - 접두사 및 강화 단계별 오오라
  를 모두 즉시 적용한다.

### 접두사별 전투 훅

- `별빛의`
  - 매직 미사일 발사 함수에서 투사체 시각 타입을 `golden_missile`로 대체
  - 피해 계산 시 인스턴스 롤 수치만큼 배수 적용

- `푸른 불꽃의`
  - 파이어볼 발사 함수에서 투사체 시각 타입을 `blue_fireball`로 대체
  - 몬스터 사망 원인 태그가 `fireball` 또는 `burn`이면 폭발 처리
  - 폭발 반경과 화상 적용은 별도 값으로 조정 가능하게 둔다

- `붉은 섬광의`
  - 체인 라이트닝 렌더 타입을 `crimson_chain`으로 대체
  - 피해 계산 시 인스턴스 롤 수치만큼 배수 적용
  - 현재 MP 회복 로직에 추가로 HP 회복을 더한다

## 오오라 설계

### 접두사 기본 오오라

- 별빛의: 옅은 금빛 후광 + 작은 별 파티클
- 푸른 불꽃의: 푸른 불꽃 안개 + 푸른 잔광
- 붉은 섬광의: 붉은 전기 후광 + 미세 스파크

### 강화 단계 오오라

- `+0 ~ +6`
  - 접두사별 은은한 기본 오오라만 표시
- `+7`
  - 더 진한 오오라
- `+8`
  - 더 진한 오오라 + 스파크
- `+9`
  - 더 진한 오오라 + 스파크 + 반짝이
- `+10`
  - 흰 오오라 중심광 + 스파크 + 반짝이
  - 접두사 색은 바깥쪽 보조광으로 유지

## UI/UX 설계

### 인벤토리

- 강화석은 수량형으로 스택
- 마력의 지팡이는 개별 인스턴스로 표시
- 무기 툴팁에 다음 정보 노출
  - 이름
  - 접두사
  - 강화 수치
  - 기본 능력치
  - 접두사 옵션 수치
  - 파괴 위험 여부

### 강화 창

- 무기 1개 + 강화석을 넣는 단순 구조
- 현재 강화 수치와 다음 강화 성공 확률 표시
- `+7` 이상은 장비 파괴 경고 문구 표시
- 실패 시 파괴 여부를 즉시 결과 모달로 명확히 전달

## 구현 순서 제안

1. 아이템 정의/접두사/강화 규칙 JSON 로더 추가
2. 인벤토리 구조를 `수량형`과 `장비 인스턴스형`으로 분리
3. 대왕 슬라임 드랍 로직에 마력의 지팡이 생성 추가
4. 모든 몬스터 글로벌 드랍에 강화석 추가
5. 장비 슬롯 및 장착 처리 추가
6. 접두사별 전투 훅 추가
7. 강화 UI 및 강화 처리 추가
8. 접두사/강화 오오라 렌더 추가

## 이번 설계의 명시적 가정

- 대왕 슬라임의 `마력의 지팡이` 드랍은 20%로 가정했다.
- 붉은 섬광의 HP 흡수는 현재 MP 회복 로직과 같은 타이밍에 추가 회복하는 구조로 설계했다.
- 실패 후 장비가 파괴되지 않으면 강화 수치는 유지되는 규칙으로 설계했다.
- 이번 단계에서는 설계서, 데이터 JSON, 인벤토리 아이콘 자산까지만 추가한다.

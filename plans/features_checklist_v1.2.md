# MMORPG 개발 마스터 체크리스트 v1.2

본 문서는 게임의 모든 기능을 매우 상세하게 분류하여, 리팩토링이나 업데이트 시 누락되는 기능이 없도록 관리하기 위한 문서입니다.
**v1.2 변경점**: 프롤로그(Prologue) 및 튜토리얼(Tutorial) 섹션 추가.

- [ ] **프롤로그 (Prologue)**
    - [ ] **연출 (Seqence)**: 게임 시작 시 화면 페이드 인/아웃(Fade In/Out) 효과가 적용되는가?
    - [ ] **대화 (Dialog)**: 가이드 NPC와의 초기 대화가 정상적으로 출력되는가?
    - [ ] **분기 (Branching)**: 대화 선택지(수락/거절)에 따라 퀘스트 시작 또는 대기 상태로 분기되는가?
    - [ ] **카메라 연출**: 특정 좌표로 카메라가 부드럽게 이동(Pan)하는가?
- [ ] **기초 훈련 (Basic Training)**

    - [ ] **허수아비 소환**: 훈련용 몬스터(Training Dummy)가 플레이어 전방에 정상 소환되는가?
    - [ ] **전투 훈련**: 기본 공격(Space)으로 허수아비를 처치하면 다음 단계로 진행되는가?
    - [ ] **퀘스트 연계**: 훈련 완료 후 가이드에게 말을 걸어 첫 퀘스트(`quest_slime_10`)를 수락할 수 있는가?
    - [ ] **UI 가이드**: 화면 중앙 또는 타겟 위치에 손가락/화살표 등으로 가이드 UI가 표시되는가?

## 1. 캐릭터 & 조작 (Character & Control)
- [ ] **이동 시스템 (Movement)**
    - [ ] **키보드 이동**: WASD 및 화살표 키로 8방향 이동이 부드러운가?
    - [ ] **모바일 조이스틱 (Dynamic Joystick)**: 터치 지점을 기준으로 생성되는 다이나믹 조이스틱으로 360도 이동이 가능한가?
    - [ ] **클릭 이동 (Click-to-Move)**: 마우스 우클릭 지점으로 캐릭터가 이동하는가? (키보드 입력 시 취소 확인)
    - [ ] **충돌 처리 (Collision)**: 맵 경계, 벽, 장애물(나무, 건물)에 막히는가?
    - [ ] **위치 동기화**: 존 입장 시 저장된 위치 또는 기본 스폰 포인트에서 시작하는가?
- [ ] **캐릭터 상태 (State)**
    - [ ] **애니메이션**: 이동(Run)/대기(Idle)/공격(Attack)/피격(Hit)/사망(Die) 애니메이션이 정상 출력되는가?
    - [ ] **방향 전환**: 이동 방향에 맞춰 **8방향(대각선 포함)**으로 캐릭터가 회전하거나 스프라이트가 변경되는가?
    - [ ] **파라미터**: HP, MP, 경험치, 레벨, 골드가 UI와 일치하는가?
    - [ ] **상세 스탯 공식 (Derived Stats)**:
        - [ ] **Max HP**: Base + (Vit * 10)
        - [ ] **Max MP**: Base + (Wis * 10)
        - [ ] **Attack Power (공격력)**: Base + (Int * 1) + (Wis / 2)
        - [ ] **Defense (방어력)**: Base + (Vit * 1)
        - [ ] **Attack Speed (공격 속도)**: 기본(1.0) + (Agi * 0.1) + (Int * 0.05)
        - [ ] **Move Speed (이동 속도)**: Base * (1.0 + Agi * 0.05)
        - [ ] **Crit Rate (치명타율)**: 기본(10%) + (Agi * 1%) + (Int * 1%)
        - [ ] **Skill CDR (쿨타임 감소)**: (Int + Wis) * 1% (Max 75%)
        - [ ] **HP Regen**: Vit / sec
        - [ ] **MP Regen**: Wis / sec

## 4. UI & UX (User Interface)
- [ ] **HUD (Heads-Up Display)**

    - [ ] **채팅창**: 엔터 키로 입력, 시스템 메시지(노란색/빨간색) 구분 표시 확인.
    - [ ] **미니맵**: 우측 상단에 플레이어(점), 몬스터(빨간점), 타 플레이어가 표시되는가?
- [ ] **메뉴 & 윈도우**
    - [ ] **인벤토리 (I)**: 아이템 아이콘 표시, 장비 장착/해제, 툴팁 확인. (골드는 0번 슬롯 고정)
    - [ ] **스킬 창 (K)**: 스킬 레벨업 버튼 (비용: 300 -> 600 -> 1200 등 배수 증가), 상세 정보 확인.
    - [ ] **스탯 창 (C)**: 스탯 포인트 분배(체력(Vit)/지능(Int)/지혜(Wis)/순발력(Agi)), 능력치 반영 확인.
    - [ ] **퀘스트 (Q)**: 현재 진행 중인 퀘스트 목표와 카운트 확인.
    - [ ] **퀘스트 목록**:
        - [ ] `quest_slime_10`: 슬라임 10마리 처치 (초반 튜토리얼)
        - [ ] `quest_slime_30`: 슬라임 30마리 처치 (보스 등장 조건)
        - [ ] `quest_boss_king_slime`: 킹 슬라임 처치 (보스전)
        - [ ] `quest_slime_repeat`: 슬라임 반복 처치 (무한 퀘스트)
    - [ ] **보상 시스템**: 퀘스트 완료 시 경험치(EXP)와 골드(Gold)가 지급되는가?
    - [ ] **알림**: 퀘스트 수락 및 완료 시 시스템 메시지와 튜토리얼 트리거가 작동하는가?

# 2026-04-25 스토리 월드 업그레이드 구현 계획

## 목표

현재 전투/성장 중심 기능을 유지하면서, `plans/Scenario.txt`의 큰 줄기를 바탕으로 플레이어가 처음 접속했을 때 바로 세계관, 감정, 이동 목표를 느끼는 1막 플레이 경험을 만든다.

이번 구현의 범위는 엔딩까지가 아니라 “살아있는 게임으로 보이는 첫 20분”이다.

## 1차 플레이 루프

1. 신규 캐릭터가 월드에 진입한다.
2. 프롤로그가 자동 재생된다.
3. 오두막과 유리카, 마석 이상 징후, 숲길 경계 목표가 제시된다.
4. 기존 튜토리얼로 이어져 조작/전투를 익힌다.
5. 바람 언덕에서 달샘 마을로 이동한다.
6. 마을에서 어둠숲으로 나간다.
7. 어둠숲에서 신규 몬스터를 상대하고 랜턴 숲 던전으로 진입한다.
8. 던전에서 랜턴 감시자를 만난다.

## 에이전트 역할 분담

- 메인 통합: 스토리 자동 시작, 컷신 UI, 포털 이동, 몬스터 단일 이미지 지원, 검증
- 스토리 콘텐츠 에이전트: `assets/data/narrative/prologue.json`
- 월드 데이터 에이전트: `zone_manifest.json`, `zone_1.json`, 신규 zone JSON 3개
- 분석 에이전트: 기존 스토리/월드/에셋 파이프라인 위험 지점 조사

## 구현 원칙

- 기존 `zone_1` 기본 스폰, 기존 슬라임 퀘스트, 튜토리얼 흐름은 유지한다.
- 신규 유저만 프롤로그를 자동으로 본다.
- 프롤로그 종료 후 기존 `basic_training` 튜토리얼로 이어진다.
- 필드 이동은 `WorldScene`의 기존 `zoneId/spawnId` 진입 구조를 재사용한다.
- 마을 존은 `monsterSpawns: []`로 명시하고, 빈 스폰 규칙이 이전 필드 규칙을 물고 오지 않도록 한다.
- 신규 몬스터는 기존 Monster/MonsterManager 전투 구조를 그대로 사용한다.

## 이번에 연결한 핵심 기능

- 신규 유저 프롤로그 자동 시작
- 스토리 대화 배경/초상 표시
- 프롤로그 `action` 실행 누락 보정
- `zone` 포털 트리거와 확인 모달
- 존별 BGM 사용
- 신규 JPEG 단일 몬스터 이미지 지원
- 마을/숲/던전 존 데이터
- 신규 몬스터 정의

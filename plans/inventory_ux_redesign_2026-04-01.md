# 인벤토리 UX 개선 설계서

작성일: 2026-04-01
대상: Yurika Online PC / 모바일 세로 / 모바일 가로

## 1. 목적

현재 인벤토리는 기능은 작동하지만, 실제 플레이 흐름에서 다음 문제가 반복된다.

- 아이템을 빠르게 훑기 어렵다.
- 모바일에서 슬롯 탐색, 상세 확인, 장착/해제 흐름이 길다.
- 장비, 재료, 소모품이 한 화면에서 뒤섞여 가독성이 떨어진다.
- 드랍 테스트와 강화 테스트 시 원하는 아이템을 찾는 데 시간이 오래 걸린다.
- 장기적으로 아이템 수가 늘어나면 300칸 구조만으로는 탐색 피로가 커진다.

이 설계의 목표는 `보는 시간`, `찾는 시간`, `행동하는 횟수`를 줄여서 인벤토리를 실제 플레이 도중 자주 열어도 부담이 없게 만드는 것이다.

## 2. 핵심 UX 원칙

1. 슬롯판이 메인이다.
인벤토리는 목록형보다 슬롯형 탐색이 우선이다.

2. 행동은 2탭 안에서 끝난다.
아이템 확인 후 장착, 해제, 강화, 사용 같은 주요 액션이 2번 이내 터치로 끝나야 한다.

3. 모바일은 엄지 우선이다.
모바일 세로는 하단 접근성, 모바일 가로는 짧은 이동 거리와 넓은 스크롤 영역을 우선한다.

4. 정렬과 분류가 없으면 300칸은 unusable 하다.
아이템이 늘어날수록 필터와 정렬 없이는 UX가 급격히 나빠진다.

## 3. 현재 구조 기준 개선 포인트

### 3-1. 슬롯 구조

- 가방 용량은 현재처럼 `300칸` 유지
- 골드는 별도 패널이 아니라 슬롯형 유틸 칸으로 유지
- 장착 무기도 별도 대형 패널이 아니라 슬롯형 유틸 칸으로 유지
- 착용 장비는 `노란 테두리`로 즉시 구분
- 강화 수치는 좌상단 `+7` 같은 짧은 배지 유지

### 3-2. 탐색 보조

아래 기능을 차례로 도입한다.

- 아이템 타입 필터: `전체 / 장비 / 재료 / 소모품 / 퀘스트`
- 정렬: `최신 획득 / 이름 / 등급 / 강화 수치`
- 검색: 이름 기준 부분 검색
- 빈 슬롯 숨기기 토글: 아이템이 있는 슬롯만 보기

## 4. 화면별 권장 레이아웃

### 4-1. PC

- 상단: 필터 탭 + 정렬 드롭다운 + 검색
- 본문: 9~10열 슬롯
- 우측 또는 중앙: 상세 모달
- 하단: `사용 슬롯 / 300`, 자동 정렬, 닫기

PC는 마우스가 있으므로 `hover 툴팁`을 추가해도 된다.

### 4-2. 모바일 세로

- 상단: `필터 탭 1줄`만
- 본문: 5열 슬롯
- 하단 고정: `사용 슬롯 / 300`, 정렬 버튼, 닫기
- 상세는 `바텀 시트` 방식

세로에서는 슬롯판이 최대한 많이 보여야 하므로, 검색창은 기본 숨김 후 탭 시 펼침이 적합하다.

### 4-3. 모바일 가로

- 상단: `필터 탭 + 정렬 아이콘` 최소형
- 본문: 7~8열 슬롯
- 상세는 중앙 혹은 우측 소형 모달
- 하단: `사용 슬롯 / 300`만 짧게 유지

가로에서는 필터 바 높이를 최소화하고, 슬롯판 높이를 확보해야 한다.

## 5. 아이템 상세 UX

현재 상세는 모달 방식이 적합하다. 다만 아래 보완이 필요하다.

- 아이템 등급 색 표시
- 접두사 효과는 일반 옵션과 분리
- 강화 성공/파괴 확률은 박스형으로 따로 분리
- 장착/해제/강화/사용 버튼은 `상황별 1~2개만` 노출

예시:

- 장비: `장착` 또는 `해제`, `강화`
- 재료: `용도 보기`
- 소모품: `사용`
- 퀘스트 아이템: 액션 버튼 없이 설명만

## 6. 편의 기능 제안

### 6-1. 정렬/정리

- 자동 정렬 버튼
- 동일 재료 자동 합치기
- 장비는 강화 수치와 접두사를 유지한 채 장비끼리만 묶기

### 6-2. 빠른 액션

- 모바일: 길게 누르기 시 빠른 액션 시트
- PC: 우클릭 또는 더블클릭 장착
- 장비 아이템은 더블탭 장착, 장착 중이면 더블탭 해제

### 6-3. 비교

- 새 무기 선택 시 현재 장착 무기와 `공격력 / 치명타 / 마나회복 / 접두사 효과` 비교
- 증가 수치는 초록, 감소 수치는 빨강

### 6-4. 잠금

- 실수 방지용 `아이템 잠금`
- 잠금된 장비는 강화 파괴 확인 시 한 번 더 경고

## 7. 추천 구현 순서

1. 필터 탭 추가
2. 자동 정렬 추가
3. 장비 비교 UI 추가
4. 모바일 길게 누르기 액션 추가
5. 검색 기능 추가
6. 잠금 기능 추가

이 순서가 좋은 이유는, 체감 UX 개선이 가장 큰 기능부터 먼저 들어가기 때문이다.

## 8. 권장 데이터/상태 구조

UI에 필요한 최소 상태:

- `inventoryFilter`
- `inventorySortMode`
- `inventorySearchQuery`
- `hideEmptySlots`
- `selectedInventoryRef`
- `inventoryQuickActionRef`

장기적으로는 아이템 객체에 아래 필드도 권장:

- `locked: boolean`
- `favorite: boolean`
- `acquiredAt: timestamp`

## 9. 결론

현재 인벤토리는 `슬롯판 중심 + 상세 모달` 방향은 맞다.
다만 진짜로 자주 쓰기 편한 인벤토리가 되려면 다음 세 가지가 반드시 필요하다.

- 필터
- 정렬
- 장비 비교

이 세 개만 들어가도 300칸 인벤토리의 탐색 피로가 크게 줄어든다.

추천 다음 작업은 `필터 탭 + 자동 정렬 + 비교 UI` 1차 적용이다.
